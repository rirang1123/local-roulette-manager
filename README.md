# 룰렛 매니저 0.1.0

Weflab 룰렛 결과를 자동으로 가져와서 OBS에서 바로 처리할 수 있게 도와주는 Windows용 프로그램입니다.

설치 과정 없이 압축만 풀고 실행할 수 있습니다.

## 이런 상황에 사용합니다

- Weflab 룰렛 결과를 방송 중에 빠르게 확인하고 싶을 때
- 리액션, 당첨, 누적 항목을 따로 관리하고 싶을 때
- 누적형 운동/시간 미션을 합산해서 처리하고 싶을 때
- OBS 화면에 타이머를 띄우고 싶을 때
- 방송 후 로그와 백업을 남기고 싶을 때

## 다운로드와 실행

1. 아래 GitHub Release 페이지로 이동합니다.
2. `Roulette-Manager-portable-folder-0.1.0-today-lock.zip` 파일을 다운로드합니다.
3. zip 파일의 압축을 풉니다.
4. 압축을 푼 폴더 안의 `Roulette Manager.exe`를 더블클릭합니다.

다운로드:

https://github.com/rirang1123/local-roulette-manager/releases/tag/v0.1.0

## 처음 실행하면 할 일

### 1. Weflab 후원알림 URL 등록

프로그램의 `설정` 화면에서 Weflab 후원알림 URL을 등록합니다.

이 URL은 실제 룰렛 결과를 감지하는 데 사용됩니다.

### 2. 룰렛 확률 공유 URL 등록

`당첨 설정` 화면에서 Weflab 시청자 룰렛 확률 공유 URL을 등록합니다.

등록하면 프로그램이 룰렛 안에 있는 항목들을 자동으로 가져옵니다.

### 3. 당첨 항목 선택

가져온 룰렛 항목 중에서 당첨으로 처리할 항목을 선택한 뒤 `당첨룰렛 지정`을 누릅니다.

나머지 항목은 자동으로 분류됩니다.

- 숫자와 단위가 있는 항목: 누적
- 그 외 항목: 리액션

예를 들어 `스쿼트 10회`, `플랭크 30초` 같은 항목은 누적으로 들어갑니다.

## OBS에 연결하기

프로그램의 `설정` 화면에 OBS용 URL이 두 개 표시됩니다.

- OBS 브라우저 독 URL
- OBS 화면 오버레이 URL

### OBS 브라우저 독

OBS 브라우저 독은 방송자가 조작하는 관리 화면입니다.

여기에서 다음 작업을 할 수 있습니다.

- 모니터링 시작/중지
- 샘플 룰렛 추가
- 리액션 없애기
- 당첨 항목 완료 처리
- 누적 항목 완료 처리
- 타이머 시작

### OBS 화면 오버레이

OBS 화면 오버레이는 시청자에게 보이는 타이머 화면입니다.

독이나 대시보드에서 타이머를 시작하면 오버레이에 타이머가 표시됩니다.

## 대시보드와 OBS 독

대시보드와 OBS 독은 같은 방식으로 구성되어 있습니다.

- 전체
- 리액션
- 당첨
- 누적

`전체`에서는 누적, 리액션, 당첨을 한 화면에서 볼 수 있습니다.

## 기간 선택

당첨과 누적은 기간을 선택해서 볼 수 있습니다.

- 일
- 주
- 월
- 시작일
- 종료일
- 오늘 날짜로 고정

`오늘 날짜로 고정`을 켜면 선택한 기간이 오늘 기준으로 고정됩니다.

## 리액션

리액션은 최근 들어온 항목이 위에 쌓입니다.

1분 뒤 자동으로 사라지며, 사라질 때까지 남은 시간이 표시됩니다. 직접 없애고 싶으면 `없애기` 버튼을 누르면 됩니다.

## 누적

누적은 같은 항목을 합쳐서 보여줍니다.

완료 처리한 항목은 합산에서 빠집니다.

초 또는 분 단위 누적 항목은 타이머로 시작할 수 있습니다.

## 데이터 저장

한 번 입력한 URL과 설정은 같은 PC에서 계속 유지됩니다.

프로그램을 껐다 켜도 다시 입력할 필요가 없습니다. 단, 다른 PC에서 실행하거나 Windows 사용자 데이터가 삭제되면 다시 등록해야 합니다.

## 로그와 백업

프로그램은 룰렛 로그를 날짜별로 저장합니다.

자동 백업도 날짜 단위로 생성되며, `백업 확인` 화면에서 확인할 수 있습니다.

## 문제가 생겼을 때

### OBS 독이 최신 화면으로 안 바뀌는 경우

OBS 브라우저 독을 새로고침합니다.

### 타이머가 송출 화면에 안 뜨는 경우

1. 프로그램이 실행 중인지 확인합니다.
2. OBS 오버레이 URL이 설정 화면의 최신 URL인지 확인합니다.
3. 독이나 대시보드에서 버튼이 `타이머 실행 중`으로 바뀌었는지 확인합니다.
4. OBS 브라우저 소스를 새로고침합니다.

### Weflab URL을 다시 입력해야 하는 경우

보통은 다시 입력하지 않아도 됩니다. 다른 PC로 옮겼거나 앱 데이터가 삭제된 경우에만 다시 등록하면 됩니다.
