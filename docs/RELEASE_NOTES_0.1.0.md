# Release Notes 0.1.0

## 배포 파일

- `Roulette-Manager-portable-folder-0.1.0-today-lock.zip`

## 포함 기능

- Weflab 후원알림 URL 감시
- Weflab 시청자 룰렛 확률 공유 URL 파싱
- 룰렛 항목 기반 당첨 설정
- 리액션/당첨/누적 자동 분류
- 대시보드와 처리 관리 통합
- OBS 브라우저 독
- OBS 송출 오버레이 타이머
- 전체/리액션/당첨/누적 탭
- 기간 단위, 시작일, 종료일, 오늘 날짜 고정
- 리액션 1분 자동 삭제와 남은 시간 표시
- 누적 미완료 항목 합산
- 타이머 실행 중 버튼 상태 표시
- 로그 저장과 일자별 자동 백업
- 백업 확인 화면
- 무설치 폴더 zip 배포

## 알려진 제한

- 앱이 실행 중이어야 OBS 독과 송출 오버레이 URL이 동작합니다.
- GitHub Pages 기반 OBS 독 파일은 인터넷 연결이 필요합니다.
- 다른 PC에서는 Weflab URL과 당첨 설정을 다시 등록해야 합니다.
