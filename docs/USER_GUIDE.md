# Local Roulette Manager 사용설명서

## 1. 설치 없이 실행하기

1. GitHub Releases에서 `Roulette-Manager-portable-folder-0.1.0-today-lock.zip`을 다운로드합니다.
2. 원하는 위치에 압축을 풉니다.
3. 폴더 안의 `Roulette Manager.exe`를 실행합니다.

설정과 로그는 앱 폴더가 아니라 Windows 사용자 데이터 영역에 저장됩니다. 같은 PC에서는 앱을 껐다 켜도 등록한 URL과 설정이 유지됩니다.

## 2. Weflab URL 등록

설정 화면에서 다음 URL을 등록합니다.

- Weflab 후원알림 URL: 실제 룰렛 결과를 감시하는 URL
- Weflab 시청자 룰렛 확률 공유 URL: 룰렛 안의 항목 목록을 가져오는 URL

확률 공유 URL을 등록하면 앱이 룰렛 항목을 가져오고, 당첨 설정 화면에서 항목별 분류를 지정할 수 있습니다.

## 3. 당첨 항목 설정

1. `당첨 설정` 화면으로 이동합니다.
2. `시청자 룰렛 확률 공유 URL`을 입력합니다.
3. `등록하고 항목 가져오기`를 누릅니다.
4. 당첨으로 처리할 룰렛 항목을 선택합니다.
5. `선택 항목 당첨룰렛 지정`을 누릅니다.

당첨으로 지정하지 않은 항목은 자동 분류됩니다.

- 숫자와 단위가 있는 항목: 누적
- 그 외 항목: 리액션

예시:

- `스쿼트 10회`: 누적
- `플랭크 30초`: 누적 및 타이머 가능
- `셀카 업로드`: 리액션

## 4. 대시보드 사용

대시보드는 OBS 독과 같은 구조입니다.

- 전체: 누적, 리액션, 당첨을 한 화면에 표시
- 리액션: 리액션 항목만 표시
- 당첨: 당첨 항목만 표시
- 누적: 누적 항목만 합산 표시

기간 조회는 `당첨`과 `누적`에 적용됩니다. `전체` 탭에서는 당첨과 누적에만 기간이 적용되고, 리액션은 현재 처리 대기 항목을 보여줍니다.

### 기간 선택

- 드롭다운: 일/주/월 빠른 기간 선택
- 시작일: 조회 시작 날짜
- 종료일: 조회 종료 날짜
- 오늘 날짜로 고정: 체크하면 오늘 기준 일/주/월 기간으로 고정하고 날짜 입력을 잠급니다.

### 리액션

리액션은 최근 들어온 항목이 위에 표시됩니다. 1분이 지나면 자동으로 사라지고, `없애기` 버튼으로 직접 제거할 수도 있습니다.

### 누적

누적은 같은 항목과 같은 단위끼리 합산합니다. 이미 완료한 항목은 미처리 합산에서 제외됩니다.

초/분 단위 누적 항목은 타이머 시작이 가능합니다.

### 타이머

타이머 시작을 누르면 버튼이 `타이머 실행 중` 상태로 바뀌고 비활성화됩니다. 송출 오버레이에는 실행 중인 타이머가 표시됩니다.

## 5. OBS 설정

설정 화면에서 두 URL을 확인합니다.

- OBS 브라우저 독 URL
- OBS 화면 오버레이 URL

### OBS 브라우저 독 추가

1. OBS에서 `독` 메뉴를 엽니다.
2. 사용자 지정 브라우저 독을 추가합니다.
3. 앱 설정 화면의 `OBS 브라우저 독 URL`을 붙여넣습니다.

브라우저 독에서는 모니터링 시작/중지, 샘플 생성, 처리 완료, 타이머 시작을 할 수 있습니다.

### OBS 오버레이 추가

1. OBS에서 브라우저 소스를 추가합니다.
2. 앱 설정 화면의 `OBS 화면 오버레이 URL`을 붙여넣습니다.
3. 타이머가 실행 중일 때 송출 화면에 표시됩니다.

## 6. 로그와 백업

전체 로그 화면에서 저장된 룰렛 기록을 확인할 수 있습니다.

- 로그는 날짜 단위로 저장됩니다.
- 자동 일일 백업이 동작합니다.
- 백업 확인 화면에서 생성된 백업 파일을 확인할 수 있습니다.

## 7. 샘플 테스트

대시보드나 OBS 독의 `샘플` 버튼을 누르면 테스트 룰렛 결과가 생성됩니다.

확률 공유 URL에서 룰렛 항목을 가져온 상태라면, 샘플은 해당 룰렛 항목 중 하나로 생성됩니다. 항목이 없으면 기본 샘플을 사용합니다.

## 8. 문제 해결

### OBS 독이 최신 화면으로 안 바뀌는 경우

OBS 브라우저 독을 새로고침합니다. 앱은 원격 OBS 독 파일에 캐시 방지 값을 붙여 로드합니다.

### 타이머가 송출 화면에 안 보이는 경우

1. 앱이 실행 중인지 확인합니다.
2. OBS 오버레이 URL이 설정 화면의 최신 URL인지 확인합니다.
3. 독 또는 대시보드에서 타이머가 `타이머 실행 중` 상태인지 확인합니다.
4. OBS 브라우저 소스를 새로고침합니다.

### URL을 다시 입력해야 하는 경우

같은 Windows 사용자 계정에서는 URL과 설정이 유지됩니다. 다른 PC로 옮기거나 사용자 데이터가 삭제된 경우에는 다시 등록해야 합니다.
